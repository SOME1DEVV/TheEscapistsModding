# ГАЙД: свой предмет + папка mods на «чистой» Steam-версии The Escapists 1

У тебя обычная Steam-версия, ничего не меняно. Ниже — всё по шагам.
Все файлы-инструменты лежат в этой папке `toolkit/`:
`te_modloader.py`, `append_item.py`, `escapists_mod.py`, `item_279_block.txt`.

> Путь игры дальше обозначен как `GAME` =
> `C:\Program Files (x86)\Steam\steamapps\common\The Escapists`

---

## 0. Подготовка (один раз)

1. **Поставь Python 3** с python.org. При установке ОБЯЗАТЕЛЬНО отметь
   **«Add Python to PATH»**. Проверка: в cmd `python --version`.
2. **Скопируй папку `toolkit`** куда-нибудь, напр. `C:\te1\toolkit`.
3. **Бэкап.** Скопируй всю папку `GAME\Data` в `GAME\Data_backup` (или просто помни:
   Steam → Свойства → «Проверить целостность файлов» вернёт оригиналы).

> В чистой Steam-версии `.dat`-файлы лежат **в открытом виде** (не зашифрованы).
> Проверить: `python escapists_mod.py detect "GAME\Data\items_rus.dat"` → скажет «не зашифрован».

---

## Шаг 1. Создать папку mods и «отключить» валидатор

```cmd
cd C:\te1\toolkit
python te_modloader.py install "GAME"
```
Что появится в `GAME`:
- `mods\` — сюда кидаешь свои `.dat`;
- `mods\_backup\` — оригиналы (откат);
- `te_modloader.py` (копия) и **`Запустить_с_модами.bat`**.

Валидатор не вырезается из exe — он **нейтрализуется**: при каждом запуске `val.dat`
пересобирается под реальные размеры файлов в `Data/`, поэтому игра стартует чисто с любыми модами.

---

## Шаг 2. Добавить свой предмет (ведро краски, ID 279)

1. Скопируй оригинал в mods:
   ```cmd
   copy "GAME\Data\items_rus.dat" "GAME\mods\items_rus.dat"
   ```
2. Дописывай блок предмета (val не трогаем — его пересоберёт лоадер):
   ```cmd
   python append_item.py --items "GAME\mods\items_rus.dat" --block item_279_block.txt --no-val
   ```
   (Хочешь своё имя/статы — сначала отредактируй `item_279_block.txt`.)

---

## Шаг 3. Запустить

Двойной клик по **`GAME\Запустить_с_модами.bat`**.
Он применит `mods\` → пересоберёт `val.dat` → запустит игру.

**Проверка в игре:** крафт «Ведро красной краски» = Чашка + Чернила (интеллект 40),
или подставь себе через Cheat Engine по ID **279**.

**Иконка:** у ID 279 в exe уже есть запасная иконка (решётка с замком) — для «просто добавить» хватит.
Хочешь именно своё ведро — PNG 16×16, прозрачный фон; вшивается маршрутом C (байт-патч exe) или B (Fusion 2.5).

---

## Как добавлять другие моды дальше
Кидаешь любой `.dat` (items_*/data_*/speech_*) в `mods\` → запускаешь bat. Всё.
Откат: `python te_modloader.py restore "GAME"`.

---

## Если что-то пошло не так
- **Игра не стартует / ругается** → запусти `restore`, проверь целостность в Steam.
- **`python` не найден** → не отметился PATH; ставь Python заново с «Add to PATH» или пиши `py -3`.
- **Файл оказался зашифрован** (`detect` сказал «зашифрован») →
  `python escapists_mod.py dec файл`, правь расшифрованный, кладй в `mods\`.
- **Предмет не виден** → убедишься, что игра на РУССКОМ (правим `items_rus.dat`);
  и что запускал через bat, а не просто Steam.
